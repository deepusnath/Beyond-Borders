# ARC — Draft Problem Statement Directions

*Status: AI-drafted directions pending anchor validation. These are conversation starters for Game Evolve's launch (Oct 2026), not build orders.*

## PS-01: Low-spec-first game design kit

A starter kit + design guide for building games that run beautifully on modest hardware (open engine, performance budgets, testing matrix), targeting the Global South device reality ARC serves. Skills: Godot/Unity, optimization discipline. Why: "next one billion gamers" is a constraint-driven design problem, and constraint-driven design is teachable.

## PS-02: Regional-language game localization pipeline

An open localization toolchain for indie games: string extraction, AI-assisted first-pass translation into Indian languages with human review flow, font/rendering checks for Malayalam and other scripts. Skills: tooling, i18n, AI-assisted workflows. Why: language is a real accessibility barrier for the next billion, and the tooling gap is open.

## PS-03: Controller-latency and input measurement rig

An open hardware+software rig measuring end-to-end input latency on consoles/PCs (photodiode + microcontroller + analysis), publishing a reproducible methodology. Skills: embedded, measurement, statistics. Why: accessible gaming hardware lives or dies on feel; open measurement builds the domain's engineering culture, and it is exactly the kind of proof-of-work an Evolve open floor loves.
